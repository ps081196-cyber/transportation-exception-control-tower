# Interview Guide

## 60-second explanation

I built a Transportation Exception Control Tower to simulate how a Network Operations Center manages last-mile execution. It monitors shipments, identifies SLA breaches, prioritizes cases using customer impact and operational severity, recommends the next action, and generates a concise stakeholder update. I also created SQL queries for station, carrier and root-cause analysis. The goal is to reduce manual monitoring time and help teams act on the highest-impact exceptions first.

## STAR discussion

- **Situation:** Transportation teams need quick visibility into late shipments and unresolved exceptions.
- **Task:** Create a repeatable method to prioritize cases and communicate network health.
- **Action:** Built Python rules, KPI calculations, an exception dashboard, SQL analysis and automated stakeholder summaries.
- **Result:** The simulation produces one prioritized queue, highlights SLA breaches and identifies recurring station/carrier issues for process improvement.

## Resume bullets

- Developed a Python and Streamlit transportation control tower to monitor last-mile shipments, prioritize SLA-breached exceptions and generate stakeholder-ready network updates.
- Automated station, carrier and root-cause analysis using pandas and SQL, enabling rapid identification of recurring operational issues and improvement opportunities.
- Designed severity-based escalation logic using exception age, customer contacts and operational risk to focus support teams on high-impact cases.
